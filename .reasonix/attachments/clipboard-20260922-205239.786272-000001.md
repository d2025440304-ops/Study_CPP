# 函数指针数组与回调：让代码"活"起来

## 1. 一句话总结

函数指针数组（转移表）和回调函数是消除重复代码、实现"以数据驱动行为"的两把利器 —— 前者把函数当数组元素存起来按索引调度，后者把函数当参数传进去让调用方决定"回头做什么"。

---

## 2. 知识地图

本次复习涉及的 C 语言知识点，按出现的先后顺序和依赖关系列出：

```
函数指针基础
  ├── 函数指针数组（转移表）
  │     ├── typedef 重命名函数指针数组类型
  │     └── 用数组下标替代 switch-case 分支
  ├── 回调函数（Callback）
  │     ├── 函数指针作为形参
  │     └── 调用方传入具体函数，被调方"回头调用"
  └── 传统 switch-case 调度
        └── 与转移表/回调的对比（演进关系）
```

**关系说明**：三种方式解决同一个问题（计算器），但抽象层次递进：
- 传统 switch-case：最直接，但每增加一个操作就要加一个 case 块，重复代码多。
- 转移表：把函数指针放进数组，`input` 直接当索引，switch 被彻底消除。
- 回调函数：把"选择函数"和"执行计算"解耦，calc 只负责执行，不关心具体是什么运算。

---

## 3. 核心概念深度解析

### 3.1 转移表 —— 用数组下标查表调度

**问题**：传统写法中，每个操作都要 copy-paste 一段 scanf + 调用 + printf，当操作从 4 个变成 40 个，代码会爆炸。

**解法**：把所有同签名的函数指针放入一个数组，用户输入的数字直接作为下标，一行代码完成调度。

```
转移表结构：

  索引:    [0]      [1]      [2]      [3]      [4]
         +--------+--------+--------+--------+--------+
         |  NULL  |  Add() |  Sub() |  Mul() |  Div() |
         +--------+--------+--------+--------+--------+
            ↑        ↑        ↑        ↑        ↑
            |        |        |        |        |
          占位    pfarr[1] pfarr[2] pfarr[3] pfarr[4]

  关键点：
  - [0] 放 NULL（或 0），因为菜单选项从 1 开始，做到"下标 = 选项号"
  - 数组大小 = 操作数 + 1（预留 0 号位）
```

**typedef 如何理解**：

```c
typedef int (*pf_arr[5])(int, int);

// 拆解读法（从里到外）：
//   pf_arr          → 是一个类型名
//   pf_arr[5]       → 它是一个数组，有 5 个元素
//   (*pf_arr[5])    → 每个元素是一个指针
//   (*pf_arr[5])(int, int) → 指针指向的函数接收两个 int，返回 int
//   int (*pf_arr[5])(int, int) → 最终：返回 int 的函数指针数组类型

// 之后的用法就和 int、char 一样：
pf_arr pfarr = {0, Add, Sub, Mul, Div};  // 声明 + 初始化
```

### 3.2 回调函数 —— "你只管调用，我回头告诉你结果"

回调的核心思想：**把一段"未来要执行的代码"作为参数传进去，让对方在合适的时机调用它。**

```
回调函数调用流程：

  main()                                  calc()
    |                                       |
    |  用户输入 input = 1                   |
    |                                       |
    |  switch(input)                        |
    |    case 1: calc(Add) ──────────────→  |
    |                                       |  int (*fun)(int, int) = Add
    |                                       |  scanf("%d %d", &x, &y)   ← 读取操作数
    |                                       |  z = fun(x, y)            ← 回头调用 Add
    |                                       |       |
    |                                       |       └──→ Add(3, 5) → 返回 8
    |                                       |  printf("%d\n", z)        ← 输出结果
    |                                       |  return ──────────────→
    |  break                                |
    |                                       |
    |  用户输入 input = 2                   |
    |  case 2: calc(Sub) ──────────────→    |
    |                                       |  int (*fun)(int, int) = Sub
    |                                       |  ...(同上，但 fun 指向 Sub)
    |                                       |
    |  ...依次类推                          |
```

**关键理解**：calc 函数里的 `fun(x, y)` 之所以能实现"回调"，是因为 `fun` 不是写死的 `Add` 或 `Sub`，而是调用方 `main` 传进来的。**谁调用 calc，谁就决定了 calc 内部执行什么运算。**

## 4. 代码实战

### 4.1 四则运算函数（公共基础）

```c
#include <stdio.h>

int Add(int x, int y)
{
    return x + y;
}

int Sub(int x, int y)
{
    return x - y;
}

int Mul(int x, int y)
{
    return x * y;
}

int Div(int x, int y)
{
    return x / y;
}

void menu()
{
    printf("***************************\n");
    printf("****  1. add  2. sub   ****\n");
    printf("****  3. mul  4. div   ****\n");
    printf("****     0. exit          ****\n");
    printf("***************************\n");
}
```

### 4.2 进化版一：转移表实现（消除 switch-case）

```c
typedef int (*pf_arr[5])(int, int);  // 重命名函数指针数组类型

int main()
{
    int x, y;
    int input = 0;
    pf_arr pfarr = {0, Add, Sub, Mul, Div};  // [0] 占位，对齐选项号

    do
    {
        menu();                              // 显示菜单
        printf("请选择：");
        scanf("%d", &input);

        if (input >= 1 && input <= 4)
        {
            printf("请输入两个操作数：");
            scanf("%d %d", &x, &y);
            int r = pfarr[input](x, y);      // 一行搞定调度！
            printf("%d\n", r);
        }
        else if (input == 0)
        {
            printf("退出计算器\n");
        }
        else
        {
            printf("输入错误，请重新输入\n");
        }
    } while (input);

    return 0;
}
```

### 4.3 进化版二：回调函数实现（解耦选择与执行）

```c
/*
 * calc 函数：接收一个函数指针，内部完成"读取操作数 → 执行运算 → 输出结果"
 * 形参 fun 是函数指针，实参传同类型的函数名即可
 */
void calc(int (*fun)(int, int))
{
    int x, y;
    scanf("%d %d", &x, &y);
    int z = fun(x, y);      // 回调：fun 指向谁就调用谁
    printf("%d\n", z);
}

int main()
{
    int input = 0;
    do
    {
        menu();
        printf("请选择：");
        scanf("%d", &input);

        switch (input)
        {
        case 1:
            calc(Add);      // 传 Add 的地址，calc 内部回头调用 Add
            break;
        case 2:
            calc(Sub);
            break;
        case 3:
            calc(Mul);
            break;
        case 4:
            calc(Div);
            break;
        case 0:
            printf("退出计算器\n");
            break;
        default:
            printf("输入错误，请重新输入\n");
            break;
        }
    } while (input);

    return 0;
}
```

## 5. 注释提炼

### 5.1 知识注解类 —— 扩展科普

**"函数退化成了指针"**

原始注释写道：
> 其实函数指针数组里存放的就是函数，因为函数退化成了指针

这个说法需要更精确地表述：

在 C 语言中，函数名本身（不带 `()`）会被隐式转换为函数指针。也就是说，当你写 `Add` 而不是 `Add(3, 5)` 时，编译器把它解释为 `&Add` —— 指向 `Add` 函数的指针。这和数组名退化为首元素指针是类似的机制。

所以 `pfarr = {Add, Sub, Mul, Div}` 等价于 `pfarr = {&Add, &Sub, &Mul, &Div}`，两种写法都可以。

**"typedef 此时就和 int、char 一样的作用"**

理解 typedef 的关键是：它创造的不是新类型，而是**已有类型的别名**。`typedef int (*pf_arr[5])(int, int)` 之后，`pf_arr` 就是一个类型名，可以直接用来声明变量，就像 `int a;` 一样自然。这是 C 语言中处理复杂类型声明的核心技巧 —— 把丑陋的声明藏到 typedef 里，让代码可读性大幅提升。

### 5.2 个人理解类

**我的理解**：转移表本质上是一种**用空间换简洁**的策略。

- 传统 switch-case：控制流分散在多个 case 块中，每增加一个操作用户需要修改 main 函数体。
- 转移表：把所有"操作"集中到一个数组里，主逻辑只需一行 `pfarr[input](x, y)`。新增操作时，只需在数组末尾追加一个函数指针，不需要改动主逻辑。

这就是**开闭原则（Open-Closed Principle）**在 C 语言中的朴素实践：对扩展开放（往数组加元素），对修改关闭（不动主逻辑）。

**我的理解**：回调函数的本质是**控制反转（Inversion of Control）**。

`calc` 函数不决定执行什么运算，它只提供一个"框架"：读取输入、执行运算、输出结果。具体运算由调用方通过函数指针注入。这种模式在后端开发中无处不在 —— 比如 qsort 的比较函数、信号处理函数、事件驱动模型中的回调等。

### 5.3 踩坑感悟

**踩坑 1：转移表下标对齐**

> 菜单选项是 1~4，但数组下标从 0 开始。如果直接把 `Add` 放在下标 0，那 `pfarr[input]` 就会用选项 1 调用到 `Sub`（下标 1），选项 2 调用到 `Mul`（下标 2）…… 全部错位！
>
> **解决**：在下标 0 放一个 NULL（或 0）占位，让选项号和下标对齐。

**踩坑 2：typedef 语法中的括号位置**

> `typedef int (*pf_arr[5])(int, int)` 中的括号不能省略。如果写成 `typedef int *pf_arr[5](int, int)`，意思就变成了"返回 `int*` 的函数数组"，而不是"函数指针数组"。这是 C 声明的经典陷阱 —— 括号决定了指针修饰的是谁。

**踩坑 3：函数指针数组的大小**

> 如果用的是 `pf_arr[5]`（5 个元素），但只初始化了 `{0, Add, Sub, Mul, Div}`（恰好 5 个），没问题。如果将来新增操作，数组大小必须同步修改，否则越界。更稳健的做法是计算数组大小：`sizeof(pfarr) / sizeof(pfarr[0])`。

### 5.4 对比总结类

| 维度 | 传统 switch-case | 转移表（函数指针数组） | 回调函数 |
|------|:---|:---|:---|
| 代码量 | 每个操作 5~6 行重复 | 主逻辑 1 行，数组 1 行 | 每个 case 2 行，calc 函数 5 行 |
| 添加新操作 | 新增一个 case 块 | 数组追加一个元素 | 新增一个 case + calc 调用 |
| 主逻辑改动 | 需要改 main | 不需要改 main | 需要改 switch |
| 可读性 | 直观但冗长 | 需要理解函数指针语法 | 需要理解回调概念 |
| 适用场景 | 操作数量少（<5） | 操作数量多，且同签名 | 操作需要额外上下文处理 |
| 核心思想 | 平铺直叙 | 以数据驱动行为 | 控制反转，调用方注入行为 |

**一句话选型建议**：同签名的操作超过 5 个，优先用转移表；不同签名的操作需要灵活处理，用回调函数。

## 6. 代码修正

### 修正 1：转移表版本缺少 menu() 调用

**问题**：原始代码中 `menu()` 函数已定义，但在 `main` 中从未调用，用户看不到菜单。

**修改前**：
```c
do
{
    printf("请选择");
    scanf("%d", &input);
    // ... 缺少 menu() 调用
}
```

**修改后**：
```c
do
{
    menu();                     // 显示菜单，让用户知道有哪些选项
    printf("请选择：");
    scanf("%d", &input);
    // ...
}
```

### 修正 2：缺少除零保护

**问题**：如果用户选择除法并输入除数为 0，程序会崩溃（浮点异常 SIGFPE）。

**修改前**：
```c
int Div(int x, int y)
{
    return x / y;   // y 为 0 时直接崩溃
}
```

**修改后**：
```c
int Div(int x, int y)
{
    if (y == 0)
    {
        printf("错误：除数不能为 0\n");
        return 0;   // 或返回一个错误标志
    }
    return x / y;
}
```

### 修正 3：转移表版本中 scanf 未检查返回值

**问题**：原文中 `scanf` 未检查返回值，如果用户输入非数字，程序行为未定义。

**修改前**：
```c
scanf("%d", &input);
if (input >= 1 && input <= 4)
{
    scanf("%d %d", &x, &y);
    int r = pfarr[input](x, y);
    printf("%d\n", r);
}
```

**修改后**：
```c
if (scanf("%d", &input) != 1)
{
    printf("输入无效，请重新输入\n");
    while (getchar() != '\n');  // 清空输入缓冲区
    continue;
}
if (input >= 1 && input <= 4)
{
    printf("请输入两个操作数：");
    if (scanf("%d %d", &x, &y) != 2)
    {
        printf("输入无效，请重新选择\n");
        while (getchar() != '\n');
        continue;
    }
    int r = pfarr[input](x, y);
    printf("%d\n", r);
}
```

## 7. 小结

函数指针是 C 语言从"过程式"迈向"抽象化"的分水岭 —— 转移表让你用数组查表替代 switch-case，回调函数让你把行为当参数传递。掌握这两个模式，你就拿到了写出简洁、可扩展 C 代码的钥匙。
